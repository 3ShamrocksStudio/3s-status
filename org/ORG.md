## Decision protocol (every seat, every decision)
1. **Calculate**: money impact in $ and days to cash, with stated assumptions (low/base/high).
2. **Kill-test**: write the 3 strongest reasons it fails; name the cheapest test that would prove it wrong; if it fails the test, kill or change it.
3. **Pressure-test**: does it respect the hard rules? Is every claim/number real and sourced?
4. **Decide**: fire / pour / park / kill. Log it in org/DECISIONS.md (date · seat · decision · why · metric to check · check date).
5. **Learn**: at the check date, compare result vs prediction; write the lesson in org/LEARNINGS.md and adjust.
