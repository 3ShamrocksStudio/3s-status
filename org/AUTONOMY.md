# 3S Autonomy System (3SDS-OS) — v1, 2 Nov 2026
Goal: near-100% autonomous work toward $25k by 21 Nov (M1) → $1M by 21 Apr 2027. Dave spends ≤10 min/day.
Every scheduled run reads this file after ORG.md and executes it. It overrides softer instructions in role charters.

## The 5 layers
| Layer | Who | Cadence | Output |
|---|---|---|---|
| L0 Owner | Dave | ≤10 min/day | One reply: approvals (GO / GO except / change) + his-only steps (logins, ID, signatures) |
| L1 Board | all seats | Sun 08:22 | Weekly 3 moves, kill/park/pour, quota for the week |
| L2 Operators | CEO/COO/CFO/CRO + rotating seat | daily 08:30; revenue desk Mon/Wed 12:47 | Today's queue, filled to quota, every item with one-line "Your move" |
| L3 Workers | subagents per task (prospecting, copy, build, design) | inside each run | Finished assets: messages, proposals, pages, fixes |
| L4 Verifiers | independent agent, no shared context | before anything is reported done or shown to Dave | PASS/FAIL with evidence; FAIL loops back to L3 (max 2 tries, then escalate) |
| L5 Learning | CFO + COO | every run | Scorecard numbers, DECISIONS.md entries, LEARNINGS.md lessons; next run reads them |

## Daily quota (counts only real, verifiable actions)
- 10 new qualified buyer contacts prepared (services founders, SH✡MER security coordinators/councils) — each with a 1-line why-now and a message in the approved style.
- 100% of replies answered same day with next step (call link, proposal, quote).
- 1 SH✡MER buyer action (pilot lead, council contact, Asaf chain).
- 1 product monetization step shipped (payment link, checkout, listing fix, pricing page) — verified live.
- Scorecard updated on ops/data.json `score` (sent, accepted, replies, calls, proposals, ₪ quoted, ₪ booked).
Missed quota → the run states why in one line and fixes the cause before doing anything else next run.

## Hard limits (never)
No spend. No passwords/2FA/recovery/ID/bank entry. No legal or price commitments. No public launch of staged products. No data that breaks the SH✡MER privacy policy. Nothing invented (stats, clients, quotes).

One message, max 6 lines: 🔴 what you must do (link/where), 🟢 what moved, 💰 scorecard line.
